## Support

Verge Kit is maintained as a technical starting point rather than a managed application support service. If you find a reproducible defect in the boilerplate, please [open an issue](https://github.com/vergekit/vergekit/issues) with the Verge Kit version, runtime environment, reproduction steps, and expected and actual behavior.

## Contributing

This project is not currently accepting external feature contributions or pull requests. This keeps the reference stack focused and its implementation decisions consistent. Clear bug reports are welcome through the issue tracker.
